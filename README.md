# LIQUIDITY LENS

Real-time liquidity and order book imbalance monitor for Vietnamese equities (academic project, not investment advice).

## Setup
```
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
```

## Run tests
```
pytest -q
```
